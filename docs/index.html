tl;dr A control plane experience for building context (signals); helps you ideate, build and inject context files into any repo.

Not another spec-driven flow. You never write a spec. You argue the idea with a panel and make the call. Signals distills the context and keeps it current; you only approve what changed.

Not another agent orchestrator. Signals stops at the PRD. Build it with Claude Code or whatever agent and workflow you already use.

What you get

Signals is a local daemon that runs the step before the code.

  • Ideate in one place. A central server at localhost:3461 hosts every repo's meetings, decisions and context in a single browser UI.
  • Inject context signals. Each repo keeps one living context: a few short files in .signals/context/ that any agent can read.
  • Bring your own orchestrator. Signals hands off PRDs in build order. Execute them with Claude Code, or copy the prompt into whatever agent or workflow you already use.
