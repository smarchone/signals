# Map
- `vocab`: shared terms every role follows
- `ceo/business`: mission, audience, non-goals, budget, big bets
- `pm/product`: what is built: feature scope, behavior, rules
- `pm/ui`: surfaces, feel, user-facing wording
- `pm/onboarding`: signup, login, invites, first-run experience
- `arch/architecture`: language, runtime, framework, hosting, datastores, schemas
- `arch/auth`: identity, sessions, credentials, OAuth
