# Partition map

CEO sits above PM and Architect. PM and Architect are peers.

| Partition | Role | Owns |
|---|---|---|
| `ceo` | CEO | mission, audience, non-goals, budget, big bets |
| `pm/onboarding` | PM | signup, login, invites, first-run experience |
| `arch/stack` | Architect | language, runtime, web framework, hosting |
| `arch/auth` | Architect | identity, sessions, credentials, OAuth |
| `arch/data` | Architect | datastores, schemas, data residency |

New partitions are added here as reviewed decisions.
